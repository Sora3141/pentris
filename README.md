# PENT! — ペントミノ落ち物パズル

テトリスを **ペントミノ（5 マスのブロック）** に拡張した落ち物パズルゲームです。
4 マスのテトリミノより形のバリエーションが多く、より複雑な戦略が求められます。

## 🔗 リンク

- リポジトリ: https://github.com/Sora3141/pentris
- デモ: https://sora3141.github.io/pentris/

## 概要

- 12 × 24 の盤面に、18 種類のペントミノを落として横一列を消す。
- ピースは 18 種類を 1 個ずつ袋に入れて順に出す（同じ形が 35 手以上来ないことはない）。`?seed=数字` で同じピース順を再現できる。
- **NEXT** 5 個表示、**HOLD**（1 手に 1 回）、ゴースト表示。ピースは最近のテトリスと同じく画面の上（見えない領域）から出現し、下の段から画面に入ってくる。次のピースが入ってくるマスに × 印を表示し、出現位置が埋まっているか、ピース全体が画面外で固定されるとゲームオーバー。
- 10 ライン消すごとにレベルアップし、落下が速くなる。
- モード: **ENDLESS**（ゲームオーバーまで）/ **500 PIECES**（500 手でのスコアを競う）。

### 得点（すべて × レベル）

| 消し方 | 点数 |
|---|---|
| 1 / 2 / 3 / 4 / 5 ライン | 100 / 300 / 700 / 1,500 / 5,000 |
| スピンで 1 / 2 / 3 / 4 / 5 ライン | 400 / 1,000 / 1,800 / 3,000 / 7,500 |
| Back-to-Back（4 ライン以上かスピン消去の連続） | 上の基本点 × 1.5 |
| REN（連続消し） | +50 × REN（10 REN で頭打ち） |
| 全消し | +3,000 |
| ソフト / ハードドロップ | 1 / 2 点 × マス（レベル倍率なし） |

スピン: 最後の操作が回転で、固定時に左右・上のどこにも動けない置き方（X ピースを除く）。

- ハイスコアと設定はブラウザに保存。

## 使用技術

- HTML / CSS / Vanilla JavaScript（ビルド不要）
- **Canvas 2D** による描画、**Web Audio** で合成した効果音

```
index.html
style.css
js/
  pieces.js    盤面サイズ・ピース定義・回転補正
  game.js      ゲーム本体（DOM 非依存）
  renderer.js  盤面・プレビュー・演出の描画
  audio.js     効果音
  input.js     キー入力（DAS / ARR）
  touch.js     スワイプ操作
  ai.js        AI（置き方の列挙・盤面評価・探索）
  ai-weights.js 学習済みの重み
  ai-worker.js AI を別スレッドで動かす
webapp-kit/     「アプリにする」「共有」ボタンとスマホ表示の対策（ほかのアプリでも共通で使う。使い方は webapp-kit/README.md）
tools/
  train.js     AI の重みを学習（クロスエントロピー法）
  bench.js     AI の強さを測定
  test.js      AI と本体の整合性テスト
  main.js      画面遷移・HUD・設定
```

## 操作

| キー | 動作 |
|---|---|
| ← → | 移動（長押しで連続移動） |
| ↓ | ソフトドロップ |
| Space | ハードドロップ |
| ↑ / X | 右回転 |
| Z | 左回転 |
| C / Shift | ホールド |
| Esc / P | ポーズ / 再開 |
| Enter | 開始 / リトライ |
| R | リスタート（ポーズ中） |

## スマホ

ボタン操作（初期設定）とスワイプ操作を切り替えられます（タイトル画面または設定から）。タイトル画面の「アプリにする」からホーム画面に追加すると、アプリとして起動します（iPhone では追加の手順を案内）。

| スワイプ | 動作 |
|---|---|
| 左右になぞる | 移動 |
| 下になぞる | ソフトドロップ |
| 下にフリック | ハードドロップ |
| タップ（左半分 / 右半分） | 左回転 / 右回転 |
| 上にフリック・HOLD 枠をタップ | ホールド |

## AI

タイトル画面の「AI のプレイを観戦」で AI が遊ぶ様子を見られます（右上のボタンで速さを 普通 / 速い / 最速 に切り替え）。

- 回転・壁蹴り・隙間へのねじ込みを含め、操作で到達できる置き方をすべて列挙する
- 各置き方を「得た点（ドロップ点込み）+ 置いた後の盤面評価」で採点し、HOLD と NEXT 1 個まで読んで最善手を選ぶ
- 盤面評価の重みは、500 PIECES モードの平均スコアが最大になるようにクロスエントロピー法で学習

```sh
node tools/test.js                       # AI の計算が本体のルールと一致するか確認
node tools/bench.js --depth 2 --games 27 # 強さを測る
node tools/train.js --depth 2 --gens 12 --pop 24   # 重みを学習して js/ai-weights.js を更新
```
